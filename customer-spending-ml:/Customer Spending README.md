# Predictive Customer Spending Behaviour

## Overview
This project applies machine learning techniques to analyse customer behaviour and predict spending patterns. The aim is to understand key factors influencing customer expenditure and to evaluate model performance in a realistic business context.

## Problem Statement
The objective of this project is to predict customer spending behaviour using historical data and to assess how different machine learning models perform when classifying customer outcomes.

## Dataset
- Source: University-provided / Kaggle dataset
- Description: Customer behavioural and transactional features, including demographic and usage variables
- Note: Dataset not uploaded due to size and usage restrictions

## Tools & Technologies
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
- Jupyter Notebook

## Methodology
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering and selection
- Model development using supervised learning techniques
- Model evaluation using confusion matrices and ROC curves

## Models Used
- Random Forest Classifier
- K-Nearest Neighbours (KNN)

## Evaluation Metrics
- Accuracy
- Precision, Recall, F1-score
- Confusion Matrix
- ROC Curve and AUC

## Key Findings / Results
- Random Forest demonstrated more stable performance across classes compared to KNN
- Feature importance analysis highlighted key drivers of customer spending behaviour
- Model evaluation metrics provided insight into strengths and limitations under real-world conditions

## Visualisations
- Feature importance plots
- Confusion matrix heatmaps
- ROC curves  
(Stored in the notebook and `images/` folder)

## How to Run
1. Clone the repository
2. Open the Jupyter Notebook
3. Run cells sequentially to reproduce results
